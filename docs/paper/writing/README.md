# Writing (English only)

Conference prose lives here. Protocol, inventory, and experiment plans stay in Chinese under `docs/paper/`.

Rules (authoritative detail is `../PROTOCOL.zh-CN.md`):

- Draft only after the user explicitly asks.
- Cite only `CLAIM-*` rows whose status is `ready` in `../claims/WORKING_CLAIMS.zh-CN.md`.
- Do not cite `EXP-*`, `RES-*`, `INV-*`, or `FIG-*` except as backing already listed on a ready claim.
- Do not invent claims, metrics, or baselines in the draft.
- Title and contribution bullets come from `../claims/SCOPE.zh-CN.md`.
- Venue constraints: `../venue/ISBI2027.zh-CN.md`.
- Do not copy `validation_results/` into this folder.

Suggested later files (do not create until needed): `outline.md`, `draft/main.tex` or `draft/main.md`, `notes/`.
