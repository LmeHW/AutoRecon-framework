## 4-page 范围

短旁证，不是第二贡献。不测 L1 启发式、不测医生三档。确认性假设家族不含本实验。

L0 合同（放行下游所必须）：

- 请求步骤的产物文件存在且 NIfTI 可读
- 体素有限（finite）
- 配准图、tissue、ROI 与约定参考的 shape/affine 一致
- 输入 fingerprint 未在中途被更换
- 未请求步骤未被执行

L1（占比、非零比例、Mattes/GC 等）只记录，**不计入** `TechnicalRunSuccess`，也不得单独放行合同 PASS。

## 设计

### 1. 真实队列（描述性）

- 纳入运行前冻结 manifest 中的全部 eligible 病例；N 以 manifest 为准，计划里不填例数。
- 固定 FROST。不按最终成败事后剔除；超时、非零退出、缺产物按预注册计入失败。
- `TechnicalRunSuccess`：请求范围内 L0 全过，且计划 / state / Dashboard / Evidence Bank / 报告对范围与 L0 终态一致。
- 报告逐步骤 L0 率与精确二项式 95% CI、失败模式、时间 median/IQR。技术合同通过 ≠ 解剖或临床通过。

### 2. 故障示范（非确认性）

从 cohort 分层抽少数病例，**只在隔离副本**注入 **2–3 类 L0 违约**（不得注入「占比偏低」却当切断测试）：

1. backend 非零退出或输出缺失
2. tissue/ROI 与配准图 shape/affine 不一致
3. fingerprint 失效或 reconstruction/registration 期间 SIGTERM（两类取一或都做，总数不超过三类）

对照：

- `Full`：L0 检查 + **执行器不启动下游**
- `Exists-only`：只检查路径存在，关闭几何/fingerprint verifier

只写隔离副本，不写公共病例目录。示范终点：检出、切断、三处文本一致；恢复（resume）可记但不当确认性主终点。

## 不在范围内

- 10×6 故障矩阵、No-verifier（只看退出码）、与 EXP-001/003 绑 Holm——已废止。
- acceptable 队列上的灵敏度/特异度、四后端优劣、Mattes 当解剖 QC、L2 医生标注。
