# 可辩护主张

`writing/` **只**引用本表中 `状态=ready` 的 `CLAIM-*`。没有第二道「可进 writing」列。

类型与状态定义见 [../PROTOCOL.zh-CN.md](../PROTOCOL.zh-CN.md) 第 3 节。新行必须是 `draft`。AI 不得自行改为 `ready`。

- `capability`：必填依据 INV；依据 EXP/RES 留空；禁止实验结果数字
- `empirical`：必填 frozen EXP 与 RES；数字必须来自该 RES
- `contribution`：必填依据 CLAIM（至少一条 empirical）；用于 [SCOPE.zh-CN.md](SCOPE.zh-CN.md) 贡献列表
